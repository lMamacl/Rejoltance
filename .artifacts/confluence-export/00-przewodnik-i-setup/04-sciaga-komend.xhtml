1. Konfiguracja i uruchamianie aplikacji

Cel

Polecenie

Pierwsze przygotowanie repozytorium po sklonowaniu (Windows)

powershell -ExecutionPolicy Bypass -File tools/setup.ps1 -TrustDevCert

Pierwsze przygotowanie repozytorium po sklonowaniu (macOS / Linux)

bash tools/setup.sh

Diagnostyka środowiska (nic nie zmienia w systemie)

powershell -ExecutionPolicy Bypass -File tools/doctor.ps1

Cała aplikacja (serwer + klient web + panel Aspire)

dotnet run --project src/Rejoltance.AppHost (albo aspire run)

Sam serwer gry (ASP.NET Core + SignalR)

dotnet run --project src/Rejoltance.Server

Sam klient webowy (w katalogu src/web)

SERVER_HTTP=http://localhost:5000 npm run dev

Prototyp referencyjny JS w przeglądarce

npx serve prototype/revibance

2. Budowanie, testy i kontrole jakości (CI lokalnie)

Cel

Polecenie

Kompilacja całej solucji .NET

dotnet build Rejoltance.slnx

Szybkie testy jednostkowe, architektoniczne i serwerowe (bez AppHost)

dotnet test Rejoltance.slnx --filter "Category!=Integration"

Test jednej reguły gry (np. R-14)

dotnet test Rejoltance.slnx --filter "FullyQualifiedName~R14"

Test dymny (smoke test) całej aplikacji z Aspire AppHost

dotnet test tests/Rejoltance.AppHost.Tests

Sprawdzenie formatowania kodu C#

dotnet format Rejoltance.slnx --verify-no-changes

Testy jednostkowe klienta React/TypeScript

npm --prefix src/web test

Kontrola typów TypeScript, ESLint i build produkcyjny klienta

npm --prefix src/web run typecheck && npm --prefix src/web run lint && npm --prefix src/web run build

Walidacja specyfikacji OpenSpec i lintera Markdown

npm run check

Odświeżenie próbki kontraktu JSON po zmianie DTO (MatchView)

UPDATE_CONTRACT_SAMPLES=1 dotnet test tests/Rejoltance.Server.Tests

5. Skille zespołu (.agents/skills/)
