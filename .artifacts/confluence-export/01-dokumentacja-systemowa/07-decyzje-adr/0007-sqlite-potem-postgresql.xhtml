Decyzja

W kontekście startu bez Dockera, wybieramy **EF Core z SQLite (plik .data/rejoltance.db) do Sprintu 3 i PostgreSQL jako kontener Aspire od Sprintu 4** zamiast PostgreSQL od razu, aby nikt nie był zablokowany instalacją, akceptując konieczność testów migracji na obu dostawcach.

Konsekwencje

Pozytywne

  • dotnet run --project src/Rejoltance.AppHost działa bez Dockera (zweryfikowane).

Negatywne / ryzyka

  • Do S4 (Sprintu 4) każdy musi mieć Docker lub Podman albo korzystać lokalnie z SQLite (#10).
  • Unikamy funkcji specyficznych dla jednego silnika bazy (np. typów JSON), jeśli nie przetestowaliśmy ich na obu.
