# 00. Przewodnik, konfiguracja środowiska i architektura SDD

Od tej sekcji zaczynasz pracę z projektem **RE:JOLTANCE**. Jest przeznaczona dla członków zespołu, prowadzącego zajęcia i agentów AI.

Znajdziesz tu:

- instrukcję konfiguracji środowiska,
- architekturę dokumentacji w podejściu Spec-Driven Development (SDD), czyli „najpierw specyfikacja, potem kod”,
- zasady codziennej pracy w Scrumie,
- słownik pojęć,
- plan migracji ze starego układu gałęzi `develop`.
